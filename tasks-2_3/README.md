# Visão por Computador - Task 2 and 3

This README aims to provide a guide to all the notebooks created, for the development of both task 2 and task 3. 

#### Task 2

For task 2, the notebook *main.py* contains the code to run all the possible alternatives that were calculated to fulfill the objective of this task. In notebooks folder there is a notebook for each alternative tested, and in run_models folder, there are also 2 other alternatives that tested the hybrid approach described in the report. 


#### Task 3

For task 3, *TASK3MainNotebook* is the notebook to follow. Other notebooks such as *CompareYoloVsFasterR-CNN* was used, as the name say, to compare performance between these two models. In the notebook *TASK3MainNotebook* there is the implementation with YOLO, as it delivered the best results, but if you want to see the implementation solely of Faster R-CNN, there is *fasterR-CNN* notebook.
